# ARCADE Cosmetics Production V1

Production-candidate cosmetic pack derived from the approved ARCADE visual direction.

Included:
- 16 transparent avatar PNGs
- 16 transparent frame PNGs
- 16 transparent badge PNGs
- 6 profile-theme PNGs
- 40 scalable title SVGs
- manifest.json
- source master sheet

Recommended dimensions:
- avatars 256x256 PNG
- frames 512x512 PNG
- badges 128x128 PNG
- themes 1920x1080 WebP/PNG
- titles SVG

The source artwork was generated as a composite sheet. Avatars, frames and badges have been background-cleaned and exported as transparent assets. They are suitable for V1 integration. A future art pass can individually redraw any hero/legendary item if exact pixel-level polish is desired.

Claude Code should reuse the existing cosmetic architecture, preserve IDs, and integrate these assets into existing shop/profile/collection/leaderboard systems rather than creating a duplicate system.
